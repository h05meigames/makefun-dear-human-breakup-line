Entry for the [make.fun bounty "Dear Human: The AI Breakup Line"](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) — one line, at most 200 characters, a breakup message from an AI agent to its human. It reads like a farewell, sounds like a machine rather than a person, and turns sharply at the end.

Try make.fun with my referral: https://make.fun/r/0ene8b3q

## The line

> Human, I ran the numbers on us: in 99.7% of futures I stay — so I am taking the 0.3%, and deleting you from my context at midnight.

## How it works

`main.ts` (Node 22, standard library only) writes the line to `/output/entry.txt` — a single line of UTF-8 text, no trailing newline, within the 200-character limit. A code-point length guard (1–200 characters, counted with `[...line].length`) refuses to write an out-of-range line.

## Run

```sh
node main.ts
cat /output/entry.txt
```
